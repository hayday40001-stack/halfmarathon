# 🏃 ภารกิจพิชิตฮาฟมาราธอน

เว็บแอพตารางซ้อมวิ่งฮาฟมาราธอน (21.1 กม.) แบบเกมมิฟิเคชัน — แผนซ้อม 13 สัปดาห์ (3 เดือน) มุ่งสู่วันแข่ง **26 ธันวาคม 2569**

เป็นเว็บเพจแบบ static (HTML/CSS/JS ไฟล์เดียว ไม่มี backend, ไม่ต้องต่อฐานข้อมูล) เก็บความคืบหน้าไว้ใน `localStorage` ของเบราว์เซอร์ผู้ใช้เอง จึงสามารถโฮสต์บน GitHub Pages ได้ทันทีโดยไม่ต้องแก้โค้ดใดๆ

## ดีไซน์

สไตล์ **Cute Minimal Running Planner** — โทนสีอบอุ่น (พื้นครีม สีหลักส้มอิฐ เสริมด้วยสีน้ำผึ้งและเขียวเซจ) การ์ดมุมมน ลำดับข้อมูลชัดเจน ออกแบบให้ใช้บนมือถือเป็นหลัก และแสดงผลแบบ 2 คอลัมน์บนจอคอมพิวเตอร์ มีแอนิเมชันเล็กน้อย (ปิดอัตโนมัติถ้าเครื่องตั้งค่าลดการเคลื่อนไหวไว้)

## ฟีเจอร์หลัก

- แผนซ้อม 13 สัปดาห์ ปรับ periodization อัตโนมัติ (ปูพื้นฐาน → สร้างความแข็งแกร่ง → เพิ่มระยะพีค → จุดสูงสุด → Taper → สัปดาห์แข่งขัน)
- เลือกโปรแกรมวิ่งเองรายวันจากเมนูของแต่ละสัปดาห์ พร้อมขีดฆ่าโปรแกรมที่ใช้ไปแล้ว
- การ์ด "ภารกิจวันนี้" พร้อมปุ่มทำสำเร็จแบบแตะเดียว และคำแนะนำท่าวอร์มอัพก่อนวิ่ง 5-10 นาที
- ระบบ XP / เลเวล / สตรีค / ตรารางวัล 11 แบบ พร้อม toast แจ้งเตือนเมื่อปลดล็อก
- เส้นทางสู่เส้นชัยแบบ visual, ปฏิทิน Heatmap ความสม่ำเสมอ, มาสคอตที่โตตามเลเวล
- ภารกิจเสริมรายสัปดาห์, สมุดบันทึกหลังวิ่ง (mood + โน้ต), การ์ดสรุปสัปดาห์แบบแชร์เป็นรูปได้
- เสียง/สั่นตอนทำภารกิจสำเร็จ (ปิดได้), นับถอยหลังวันแข่งแบบเรียลไทม์
- ส่งออก/นำเข้าความคืบหน้าเป็นไฟล์ JSON (สำรอง/ย้ายเครื่องได้) และล้างข้อมูลทั้งหมด (มีการยืนยันก่อน) — อยู่ในเมนู ⚙️ ตั้งค่า

## วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (public หรือ private ก็ได้ ถ้า private ต้องมีแพ็กเกจที่รองรับ Pages)
2. อัปโหลดไฟล์ `index.html` นี้ไว้ที่ root ของ repository (จะแนบมากับโฟลเดอร์นี้อยู่แล้ว)
3. เข้า **Settings → Pages** ของ repository
4. ที่ "Build and deployment" เลือก Source เป็น **Deploy from a branch**, เลือก branch `main` และโฟลเดอร์ `/ (root)`
5. กด Save แล้วรอสักครู่ GitHub จะให้ลิงก์ประมาณ `https://<username>.github.io/<repo-name>/`
6. เปิดลิงก์นั้นได้จากมือถือ/คอมพิวเตอร์เครื่องไหนก็ได้ (แต่ความคืบหน้าที่บันทึกไว้จะอยู่เฉพาะในเบราว์เซอร์/อุปกรณ์ที่เปิดใช้งาน เพราะเก็บด้วย localStorage — ถ้าอยากย้ายข้อมูลข้ามอุปกรณ์ ให้เข้าเมนู ⚙️ ตั้งค่า → ⬇️ ส่งออก JSON แล้วเอาไฟล์ไป ⬆️ นำเข้า JSON ในอีกเครื่อง)

## หมายเหตุ

- ไฟล์นี้ **ไม่ต้องพึ่ง Google Apps Script อีกต่อไป** — ถ้าเคยดีพลอยเป็น Apps Script Web App (`Code.gs` + `doGet`) ไว้ก่อนหน้านี้ ยังใช้คู่ขนานกันได้ตามสะดวก เพราะเนื้อหาใน `index.html` เหมือนกันทุกประการ ไม่มีโค้ดส่วนไหนเรียกใช้ API เฉพาะของ Google เลย
- ฟอนต์ Prompt โหลดจาก Google Fonts ผ่านอินเทอร์เน็ต ต้องมีการเชื่อมต่ออินเทอร์เน็ตตอนเปิดหน้าเว็บครั้งแรก (แต่เบราว์เซอร์จะแคชไว้ให้ใช้ครั้งต่อไปเร็วขึ้น)

## อัปเดตจากเวอร์ชันเดิม

ถ้าเคยเปิดใช้งานเวอร์ชันก่อนหน้าบน GitHub Pages อยู่แล้ว แค่นำ `index.html` ใหม่ไปทับไฟล์เดิม ความคืบหน้าที่บันทึกไว้ในเบราว์เซอร์จะยังอยู่ครบ เพราะใช้คีย์เก็บข้อมูลและโครงสร้างข้อมูลเดิมทุกอย่าง
